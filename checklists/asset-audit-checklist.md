# Asset Audit Checklist

## Before the audit
- [ ] Define scope (locations, categories, departments) and date range
- [ ] Export the current asset register (see `templates/asset-inventory.csv`)
- [ ] Freeze or log moves and assignments during the count window
- [ ] Assign auditors and split the list by location
- [ ] Prepare a count sheet or scanning method

## During the audit
- [ ] Physically locate every listed asset; confirm tag and serial number match
- [ ] Record location, assignee and condition
- [ ] Note untagged assets found on site
- [ ] Flag assets listed but not found
- [ ] Photograph damaged or high-value items

## Reconciliation
- [ ] Update locations and assignees
- [ ] Investigate missing assets (last known holder, offboarding records)
- [ ] Add found-but-unrecorded assets
- [ ] Mark retired/disposed assets and record the disposal method
- [ ] Record the audit date on each verified asset

## Reporting
- [ ] Accuracy rate = verified assets / listed assets
- [ ] Missing count and estimated value
- [ ] Root causes and process fixes
- [ ] Schedule next audit (quarterly for high-value, annually for the rest)
