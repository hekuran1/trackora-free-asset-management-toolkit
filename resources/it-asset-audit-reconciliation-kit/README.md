# IT Asset Audit and Reconciliation Kit

Audit planning worksheet, physical audit execution checklist, four discrepancy reports (missing, unexpected, wrong location, condition), follow-up tracker, findings summary, and an Excel workbook that reconciles an expected list against a found list for one audit exercise (up to 40 items, fictional worked example).

**Use it for:** Carrying out a physical equipment audit and documenting what you find. It is not an asset register.
