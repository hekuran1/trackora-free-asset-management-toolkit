# Equipment Loss and Recovery Toolkit

A six-step workflow for missing, lost or unreturned equipment: incident form, investigation checklist, departure recovery checklist, return escalation tracker, recovery outcome report, management report and an implementation guide.

**Use it for:** Handling equipment that is unaccounted for, in a repeatable way.
