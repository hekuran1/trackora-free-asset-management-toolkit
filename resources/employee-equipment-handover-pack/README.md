# Employee Equipment Handover Pack

Six fillable forms: equipment assignment, employee acknowledgement, return form, offboarding recovery checklist, missing or damaged equipment report and manager sign-off.

**Use it for:** Issuing equipment, taking it back, and when an employee leaves.
