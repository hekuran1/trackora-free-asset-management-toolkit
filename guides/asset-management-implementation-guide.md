# Asset Management Implementation Guide

1. **Define the goal.** Reduce loss? Speed up onboarding? Pass audits? Control cost? Pick two or three measurable outcomes.
2. **Decide scope.** Start with the assets that hurt most when lost: laptops, phones, monitors, AV gear, high-value tools.
3. **Design the record.** Use `templates/asset-inventory.csv` as a baseline. Required fields: tag, category, serial, status, location, owner.
4. **Do a baseline count.** Walk every location and reconcile with purchasing and HR records.
5. **Tag everything.** See the [QR labeling guide](qr-asset-labeling-guide.md).
6. **Define lifecycle statuses.** On order, In stock, In use, In repair, Retired, Disposed. Decide who may change each.
7. **Standardize handovers.** Use the handover and checkout templates for every issue and return.
8. **Tie into HR events.** Onboarding issues equipment; offboarding triggers a return checklist.
9. **Audit regularly.** See the [audit checklist](../checklists/asset-audit-checklist.md).
10. **Report.** Track audit accuracy, missing assets, average time to issue equipment, and asset age.
11. **Review annually** and plan refresh cycles from age and warranty data.

## Common pitfalls
- Multiple spreadsheets with no single owner
- Untagged assets
- No return process at offboarding
- Data entry only at purchase, never on moves
